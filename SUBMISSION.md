# Community directory submission

- Repository: https://github.com/jackiexu001/video-transcript-obsidian-fetch
- Plugin ID: `video-transcript-fetch`
- Name: Video Transcript Fetch
- Candidate version/tag: `3.1.2` (release prepared for submission)
- Author: Larry Xu
- Minimum Obsidian: `1.13.0`; desktop only.
- Description: Save Bilibili and YouTube transcripts as notes, using optional speech recognition when captions are unavailable.
- Category suggestion: Import / integration.
- Payment disclosure: free platform-caption import; optional third-party speech recognition requires the user's account/API key and may incur charges.
- Account disclosure: Bilibili login may be needed for captions. No project-service account is required.

Current official procedure: sign into https://community.obsidian.md/ with the owner's Obsidian account, link GitHub, add the repository, and resolve automated review feedback. The default branch must contain README.md, LICENSE and manifest.json at the root. The public release tag must exactly match the manifest version and have main.js, manifest.json and styles.css as individual attachments. A ZIP alone is not sufficient.

Before pressing Publish, review the live evidence in ACCEPTANCE.md and the source history in PROVENANCE.md/REVIEW.md. Do not describe this as a formally certified clean-room implementation or promise all videos are accessible. If the directory regards it as a fork, follow its fork policy rather than hiding the relationship or erasing notices.
